Share your keyboard & mouse

Keep them plugged into Windows. Deskflow can send your keyboard and mouse to the Mac over your local network.

  1. Install Deskflow on both computers and keep both awake on the same network.
  2. In Deskflow, make Windows the server (share this computer’s keyboard and mouse) and the Mac the client.
  3. Connect the Mac to the Windows address. Verify the server fingerprint, and allow macOS Accessibility and Input Monitoring when requested.
  4. In the Windows server layout, place the Mac to the right. After switching the monitor, move your pointer past the right edge to control the Mac. Move left to return.

Screen input and keyboard focus are separate. Switchy changes the monitor input; Deskflow changes which computer receives your input. Switchy does not bundle or automatically configure Deskflow.

If the monitor doesn’t switch

Check the selected monitor and HDMI port, turn on DDC/CI in the monitor’s own menu, and connect both computers directly if possible.

Some monitors ignore commands from an inactive port. If switching back fails, use Switchy on the computer currently displayed, or the monitor’s physical input button. A cable or adapter can also block DDC.

The Apple silicon download includes m1ddc. Mac HDMI support depends on the port and monitor; a USB-C to DisplayPort cable is an alternative if HDMI control fails.
