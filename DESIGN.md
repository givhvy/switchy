# Switchy

Approved direction: compact, warm-neutral desktop utility with one prominent switch button. Apply the design filter during the build.

Reading this as: a desktop input selector for one Windows PC and one MacBook, with the feel of a small physical desk accessory. ENERGY 2 / RHYTHM 1 / MOTION 1.

- Warm ivory and ink make the window comfortable beside daily work. An olive switch button marks the primary action.
- System fonts keep settings familiar on each operating system. The product name is a text wordmark.
- A two-position rail echoes the monitor's two connected computers and distinguishes direct selection from toggle.
- Settings sit below the action in native disclosure sections, so setup does not obscure everyday use.
- Radius is 8px on inputs, 14px on the main panel. No decorative gradients, glass, shadows or continuous motion.
- Status comes only from native control results. A sent command is not presented as a visually confirmed input change.
- The tray's two-contact glyph identifies the selector when the main window is closed.
